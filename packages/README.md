# The Building Blocks (packages/)

These are the parts that make Essential work:

- **`ai/`** — the writing and thinking (strategy, copy, and the AI connection)
- **`approvals/`** — the two-step approval system (you approve before anything posts)
- **`auth/`** — logins and passwords
- **`core/`** — shared helpers (error handling, logging, retries)
- **`heygen/`** — talking-head video
- **`media/`** — video and image production
- **`neo/`** — the built-in AI assistant that answers questions about Essential
- **`oauth/`** — safe platform logins
- **`persistence/`** — where drafts are saved
- **`tools/`** — the extra tools Essential can use
